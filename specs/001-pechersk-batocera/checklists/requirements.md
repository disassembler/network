# Requirements checklist

- [x] Source read-only boundary is explicit.
- [x] User journeys and measurable software/hardware acceptance are separate.
- [x] Hardware and populated library are based on direct inspection.
- [x] Runtime secrets and persistent game data stay out of Git/store.
- [x] Save compatibility and custom-script limitations are explicit.
- [x] Installation storage selected.
- [x] Frontend strategy selected after package-removal findings.
- [x] Implementation plan and tasks reviewed for coverage before coding.
- [x] NixOS and Colmena evaluation, host build and importer validation recorded.
- [x] Graphical test environment failure and hardware acceptance boundary recorded honestly.
